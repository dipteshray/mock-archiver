# AES-IGE in Rust instead of pure Python. Telethon picks it up automatically the
# moment it is importable - no code change, no behaviour change, same wire
# protocol. Without it every byte is encrypted by `pyaes` in the interpreter,
# which measured 0.22-0.38 MB/s in the course migration versus 15-16 MB/s with
# it. Included from the start here rather than discovered later.
#
# cryptg 0.6.0 ships a cp311 manylinux_2_28_x86_64 wheel, which is exactly what
# ubuntu-latest + python-version '3.11' resolves to, so the runner installs a
# prebuilt binary and never compiles anything.
cryptg==0.6.0
